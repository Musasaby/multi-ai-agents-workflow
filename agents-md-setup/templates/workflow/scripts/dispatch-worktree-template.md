## worktree で実行する場合の追加の指示

- 作業ディレクトリは git worktree `{workdir}` です。ファイルの読み書きとコマンドの実行は、すべて `{workdir}` の中で行ってください。相対パスは `{workdir}` を基準に読んでください
- 本体の作業ツリー `{main_root}` のファイルのうち、`{workdir}` の外にあるものは読み書きしないでください。変更は親が worktree から本体へ取り込みます
- 「前提タスクの成果(引き継ぎ)」の節がある場合、そこに絶対パスで挙げた完了報告(report.md)は `{workdir}` の外にありますが、読んでください。書き込みはしないでください
